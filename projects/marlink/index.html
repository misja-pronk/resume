MARLINK

Implementing a Big Data Platform with Azure Technologies

Role Data Engineer
Duration 7 MONTHS
Via Motion10
Status ✓ DELIVERED

Marlink provides mobile services to the maritime sector and accumulates huge amounts of data that need to be analyzed to improve its services. The company needed a big data platform built on PaaS services, preferably with a pay-as-you-go model.

My role was to design the platform, set up CI/CD, define development standards for a multidisciplinary team of 5 people, develop the ELT for the Boskalis pilot and be responsible for quality assurance.
