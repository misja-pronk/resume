VeiligheidNL verwerkt data over verkeersincidenten voor de Nederlandse overheid, aangeleverd door ziekenhuizen en andere medische instellingen. Vanwege de AVG moet alle data die niet aan verkeersincidenten gerelateerd is worden uitgefilterd. Hiervoor werd een machine-learning-model gebouwd, dat werd opgenomen in een publieke API waar ziekenhuizen hun informatie kunnen uploaden.

Als data engineer was ik verantwoordelijk voor het ontwerpen en bouwen van de API en het verbeteren van de CI/CD-pijplijnen.
