TBI's Shared Service Center provides IT services to 17 companies in the construction and infrastructure sectors. Given the large number of data sources — hundreds — that needed to be integrated into the data platform, I designed and developed a metadata-driven solution to solve this problem.

I also set up CI/CD, defined the development standards, trained the client's staff and migrated the SSIS functionality to Azure Data Factory.
