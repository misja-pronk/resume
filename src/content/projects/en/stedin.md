Stedin had just migrated its on-premises data warehouse (Oracle, Informatica) to a big data platform in Azure built on HDInsight, Informatica and SQL Server Managed Instance. After the migration, Stedin struggled to keep the platform running and asked for an assessment of the current solution.

I was responsible for interviewing stakeholders, identifying the technical and organizational issues and creating an improvement plan.
